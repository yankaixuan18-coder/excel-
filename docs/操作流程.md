# 详细操作流程（从零到每周一键）

> 跟着做就行。分两大块：**一次性设置**（阶段 0–5，只做一次）和 **每周操作**（阶段 7，每周一条命令/双击一次）。
> 截图里的"光伊"店铺只是举例，多个店铺照着配多份即可。

---

## 阶段 0：装好 Python（只做一次）

本工具用 Python 运行，需要 **3.11 或更高版本**。

- **Windows**：去 <https://www.python.org/downloads/> 下载安装，安装第一屏**务必勾选 "Add Python to PATH"**。
- **Mac**：用自带的，或 `brew install python@3.11`。

装完打开**终端**（Windows 叫"命令提示符 cmd"或"PowerShell"；Mac 叫"终端 Terminal"），输入下面这行验证：

```bash
python --version
```

显示 `Python 3.11.x`（或更高）就对了。
> 注意：有些电脑要用 `python3` 和 `pip3` 代替 `python` / `pip`。下文命令二选一即可。

---

## 阶段 1：拿到代码并安装依赖（只做一次）

**方式 A（推荐，会用 git）**

```bash
git clone <你的仓库地址>
cd excel-
git checkout claude/relaxed-wright-9uexvg
```

**方式 B（不熟悉 git）**：到 GitHub 仓库页面 → 切到分支 `claude/relaxed-wright-9uexvg` → 点 `Code` → `Download ZIP` → 解压 → 用终端 `cd` 进入解压出来的文件夹。

进入文件夹后安装依赖（只有一个 `requests`）：

```bash
pip install -r requirements.txt
```

---

## 阶段 2：拿到 3 个凭据值（只做一次）

打开 <https://docs.qq.com/open/> 登录，完成"开发者资质认证"（显示**审核通过**即可）。
在「**开发者信息**」页面，你会看到 3 个值，直接**点"复制"**记下来：

- **client_id（应用ID）**
- **access_token**（有效期约 30 天，过期了回这个页面重新复制即可）
- **open_id**

> 有了这三个值就够了 —— **不需要 client_secret，也不需要跑授权（阶段 5 可跳过）**。
> 官方说明：<https://docs.qq.com/open/document/app/get_started.html>

---

## 阶段 3：找到「文档ID」和「子表ID」（只做一次，每个店铺各一份）

- **文档ID（book_id）**：在浏览器里打开你的周利润表，看地址栏：
  ```
  https://docs.qq.com/sheet/ABCDEFG123   ← 斜杠后面这串就是 book_id
  ```
- **子表ID（sheet_id）**：一个文档里有多个标签页（伍纺源 / 昕亦 / 光伊 / 春知处…），每个标签页是一个"子表"。
  - 切到目标标签页时，地址栏里常带 `tab=xxxx` 或 `sheet=xxxx`，那个 `xxxx` 就是 sheet_id；
  - 如果看不到，先把 book_id 填进配置，跑一次 `python run.py raw-read`（见阶段 6），按返回信息确认正确的 sheet_id。

---

## 阶段 4：填写 config.toml（只做一次）

复制模板：

```bash
cp config.example.toml config.toml      # Windows 可用: copy config.example.toml config.toml
```

用记事本/编辑器打开 `config.toml`，填这几项：

```toml
[app]
client_id    = "阶段2复制的 client_id"
access_token = "阶段2复制的 access_token"
open_id      = "阶段2复制的 open_id"

[[targets]]
name      = "光伊"          # 名字随便起，命令行 --target 用它
book_id   = "阶段3的文档ID"
sheet_id  = "阶段3的子表ID"
date_col   = "A"           # 日期列，一般 A
marker_col = "B"           # 判断块到哪行结束的列（块内每行都有值，一般是 SKU 列）
last_col   = "AL"          # 你最右边那个数据列
clear_cols = ["E","F","G","H","J","P","S","V","X","Y"]   # 每周手填的"实际数据列"，新块留空
year       = 2026
```

**`clear_cols` 怎么填**：把你**每周手动录入的原始数据列**（可售天数/库存/销量/订单/销售额/评论/点击/花费…）写进去，新块这些格会留空等你填。
- 公式列（CPC/ROAS/转化率、父ASIN 汇总的 SUM）**会自动保留**，写不写进去都不会被破坏。
- 想"连上周数字一起整块复制"就写 `clear_cols = []`。

**多个店铺**：复制多份 `[[targets]]`，各填各的 `name / book_id / sheet_id / last_col / clear_cols`。

---

## 阶段 5：授权（直填 token 模式可**跳过**）

如果你按阶段 4 填了 `access_token` + `open_id`，**这一步不用做**，直接进入阶段 6。

（仅当你不直填 token、而想走浏览器授权时才需要：先在 config 填 `client_secret`/`redirect_uri`，
再运行 `python run.py auth` 登录同意。`access_token` 过期了就回阶段 2 的页面重新复制粘贴一次。）

---

## 阶段 6：试跑（第一次强烈建议在「副本文档」上做）

> 先复制一份你的周利润表当测试副本，把副本的 book_id/sheet_id 填进去试，确认效果对了再用到正式表。

**第 1 步 —— 只读预览，确认识别对不对：**

```bash
python run.py read --target 光伊
```

会打印类似：
```
[光伊] 上一周块: 第 1042-1046 行 (共 5 行), 日期 = 6.7-6.13
[光伊] 将新增:   第 1047-1051 行, 新日期 = 6.14-6.20
```
对照你的表核对：行号、日期是不是你期望的下一周。**不对就先别往下走**（多半是 `date_col` / `marker_col` 填错）。

**第 2 步 —— 预览将要写入的内容（仍然不写）：**

```bash
python run.py run --target 光伊
```

会显示公式/常量/留空各多少个，以及要发送的请求预览。

**第 3 步 —— 确认无误，真正写入：**

```bash
python run.py run --target 光伊 --apply
```

打开腾讯文档看新增的那一块，检查：日期对不对、公式有没有指向自己这行、手填列是不是空的。

> 排查读取问题用：`python run.py raw-read --target 光伊 --range A1:B5`

---

## 阶段 7：每周例行操作（以后每周就这一步）

```bash
python run.py run --target 光伊 --apply
```

多个店铺就多跑几条（换 `--target`）。

### 让它变成"双击一下"（可选，最省事）

把每周要跑的命令写进一个脚本，以后**双击**就行：

- **Windows**：新建 `每周更新.bat`，内容：
  ```bat
  @echo off
  cd /d %~dp0
  python run.py run --target 光伊 --apply
  python run.py run --target 昕亦 --apply
  python run.py run --target 春知处 --apply
  python run.py run --target 伍纺源 --apply
  pause
  ```
- **Mac**：新建 `每周更新.command`，内容：
  ```bash
  #!/bin/bash
  cd "$(dirname "$0")"
  python3 run.py run --target 光伊 --apply
  python3 run.py run --target 昕亦 --apply
  ```
  保存后执行一次 `chmod +x 每周更新.command` 赋予运行权限。

以后每周双击这个文件，所有店铺一次更新完。

## 常见问题速查

| 现象 | 可能原因 / 怎么办 |
|------|------------------|
| `read` 报"没找到日期区间" | `date_col` 填错，或日期格式不是 `5.31-6.6` |
| 识别的块行数不对 | `marker_col` 选的列在块内有空行；换一个块内每行都有值的列 |
| 新日期算错 | `year` 填错；或这周不是 +7 天（改 `step_days`） |
| 授权失败 / 接口报错 | 见 `docs/API_NOTES.md`：可能是接口版本/字段名要对照官方文档微调 |
| 读不到数据 | 先 `raw-read` 看真实返回结构，按 `docs/API_NOTES.md` 调 `client._parse_grid` |

> ⚠️ 联网接口部分是依据公开资料实现、未在开发环境联调过，**首次使用务必按 `docs/API_NOTES.md` 对照官方文档核对一遍**，并始终先看 dry-run 再 `--apply`。
