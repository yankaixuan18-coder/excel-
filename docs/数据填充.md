# 自动填数（按 ASIN + 站点匹配）

复制出新一周的空块后，工具可以**自动把每周实际数据填进去**：按每行的 ASIN + 该标签页的站点，去你导出的数据表里查，填进对应的数据列。

## 工作流

1. 每周从领星ERP（或其它）导出数据表 `xlsx`，覆盖到固定路径（如 `data/weekly.xlsx`）。
   - 数据表第一行是表头，A 列是 `ASIN；国家`（中文分号 `；`，国家中文：美国/加拿大/英国/法国/德国/意大利/西班牙）。
2. 在 `config.toml` 配置 `data_table` 路径、列映射 `fill_map`、每个 target 的站点。
3. 跑 `python run.py run --all`：先复制整块、清空 BC 之后的备注列、填日期，再按 ASIN+站点填数。

不配 `data_table` 就只做"复制行 + 填日期"，不填数。

## 站点怎么定（按标签页）

每个 `[[targets]]` 的站点按这个优先级确定：

1. `country = "加拿大"`（直接写中文，最高优先级）
2. `country_code = "CA"`（代码：CA/US/UK/GB/FR/DE/IT/ES）
3. 从标签名 `name` 前缀解析：`CA外卖包-王倩` → `CA` → 加拿大
4. 都没有 → 默认 **美国**

> 代码→中文：CA=加拿大, US=美国, UK/GB=英国, FR=法国, DE=德国, IT=意大利, ES=西班牙。

## 列映射 fill_map（关键）

`fill_map` 把**表格的列字母**对应到**数据表的字段名**。全局写在 `[app.fill_map]`，
个别表不同可在该 `[[targets]]` 里用 `fill_map = {...}` 覆盖。

```toml
[app.fill_map]
F = "inventory"        # 库存
G = "sales_volume"     # 销量
H = "order_quantity"   # 订单
J = "sales_revenue"    # 销售额
# ... 按你表格的真实列继续
```

**两条重要规则（让填数很安全）：**

- **公式永远不被覆盖**：表里是公式的列（转化率/CPC/ROAS/ACoS、父ASIN 汇总的 SUM 等），
  即使写进 `fill_map` 也只会用公式自动算，不会被数据值盖掉。所以你可以放心多映射。
- 只有"非公式、且匹配到数据"的格才会被填；匹配不到的行/字段保持空。

## 多表 / 多标签页

每个标签页配一个 `[[targets]]`（同一文档多个标签页 `book_id` 相同、`sheet_id` 不同）。
一次跑完所有：

```bash
python run.py run --all            # 先全部 dry-run 预览
python run.py run --all --apply    # 确认后全部写入
```
